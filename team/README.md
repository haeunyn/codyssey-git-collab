# team — 팀원 소개 (결과물)

우리 팀은 과제의 "간단한 결과물" 중 **(B) 팀 소개**를 선택했습니다.
각자 이 폴더에 `<이름>.md` 파일을 하나 만들고, 저장소 맨 앞 `README.md` 의 **팀원 표**에 자기 줄을 추가합니다.

## 추가하는 법

1. **Issue 만들기** — 제목 예: `docs: add <이름> intro`
2. **브랜치 만들기** — `git switch -c feature/<이름>-intro`
3. **파일 작성** — `team/<이름>.md` (아래 양식 복사)
4. **README 팀원 표에 내 줄 추가** — 이름 · GitHub · 소개 링크 · 담당 (같은 PR 에 포함)
5. **커밋** — `docs: add <이름> intro to team`
6. **push 후 PR** — 본문에 `Closes #이슈번호`

> 두 번째 PR 거리 예: 소개에 항목 추가하기, 다른 사람 소개의 오타 고치기, 표 정리하기

## 양식

```markdown
# <이름>

- GitHub: @<아이디>
- 한 줄 소개:
- 코디세이에서 하고 싶은 것:
- 좋아하는 것:
```
